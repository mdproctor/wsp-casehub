# Distributed Executor Protocol Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> subagent-driven-development (recommended) or executing-plans to
> implement this plan task-by-task. Each task follows TDD
> (test-driven-development) and uses ide-tooling for structural
> editing. Steps use checkbox (`- [ ]`) syntax for tracking.

**Focal issue:** #418 — Distributed executor protocol
**Issue group:** #418 (protocol), part of epic #408

**Goal:** Implement the distributed executor protocol so the orchestrator
can dispatch ordered step sequences to browser and service executors with
stepping, speed control, and a controller API for demo operation.

**Architecture:** Pages Java server is the orchestrator. It parses
hierarchical scenario YAML (chapters/sections/steps/commands), builds a
trigger graph, and dispatches step sequences to executors via new
PushRequest/PushMessage types over the existing push wire WebSocket.
Executors run steps locally and report results back. A REST controller
API enables demo operation from any device.

**Tech Stack:** Java 21 (sealed interfaces, records, pattern matching),
Quarkus (CDI, REST), Jackson (JSON), TypeScript (Lit web components),
Vitest (TS tests), JUnit 5 + AssertJ (Java tests)

## Global Constraints

- All new Java types use records and sealed interfaces where applicable
- PushRequest/PushMessage changes go in `backend/push` module
- Scenario model types go in `backend/scenario` module
- Orchestrator goes in `backend/scenario-runtime` module
- New `backend/scenario-client` module for the shared executor library
- Speed must be > 0 (minimum 0.01). Use `pause` control for zero speed
- Session ID is a UUID generated by the orchestrator
- Labels must be unique within their hierarchy level
- All tests use JUnit 5 + AssertJ (Java) or Vitest (TypeScript)

package io.casehub.pages.scenario;

import java.util.List;
import java.util.Map;
import java.util.Objects;
import java.util.stream.Stream;

public record HierarchicalScenario(
        String scenario, String description,
        double speed, String onError,
        Map<String, Object> data,
        List<ScenarioChapter> chapters,
        List<ScenarioSection> sections,
        List<HierarchicalStep> steps) {

    public HierarchicalScenario {
        Objects.requireNonNull(scenario, "scenario");
        data = data != null ? Map.copyOf(data) : Map.of();
    }

    public Stream<HierarchicalStep> allSteps() {
        if (chapters != null) {
            return chapters.stream()
                .flatMap(c -> c.sections().stream())
                .flatMap(s -> s.steps().stream());
        }
        if (sections != null) {
            return sections.stream().flatMap(s -> s.steps().stream());
        }
        return steps != null ? steps.stream() : Stream.empty();
    }
}
```

public final class SequencePartitioner {
    public record StepSequence(String target, List<HierarchicalStep> steps) {}

    public static List<StepSequence> partition(List<HierarchicalStep> steps) {
        var result = new ArrayList<StepSequence>();
        String currentTarget = null;
        List<HierarchicalStep> currentGroup = null;
        for (var step : steps) {
            if (!step.target().equals(currentTarget)) {
                if (currentGroup != null) {
                    result.add(new StepSequence(currentTarget, List.copyOf(currentGroup)));
                }
                currentTarget = step.target();
                currentGroup = new ArrayList<>();
            }
            currentGroup.add(step);
        }
        if (currentGroup != null && !currentGroup.isEmpty()) {
            result.add(new StepSequence(currentTarget, List.copyOf(currentGroup)));
        }
        return result;
    }
}
```

@ApplicationScoped
public class ScenarioControlResource {
    @Inject ScenarioOrchestrator orchestrator;

    @POST @Path("/start")
    public ScenarioState start(StartRequest req) {
        orchestrator.start(req.yaml());
        return orchestrator.state();
    }

    @POST @Path("/pause")
    public ScenarioState pause() { orchestrator.pause(); return orchestrator.state(); }

    @POST @Path("/resume")
    public ScenarioState resume() { orchestrator.resume(); return orchestrator.state(); }

    @POST @Path("/step")
    public ScenarioState step() { orchestrator.step(); return orchestrator.state(); }

    @POST @Path("/run-to")
    public ScenarioState runTo(RunToRequest req) {
        var result = orchestrator.runTo(req.label());
        if (result == RunToResult.NOT_FOUND) throw new NotFoundException("Label not found: " + req.label());
        if (result == RunToResult.ALREADY_PAST) throw new BadRequestException("Already past: " + req.label());
        return orchestrator.state();
    }

    @POST @Path("/speed")
    public ScenarioState speed(SpeedRequest req) {
        orchestrator.speed(req.speed());
        return orchestrator.state();
    }

    @GET @Path("/state")
    public ScenarioState state() { return orchestrator.state(); }
}

@ApplicationScoped
public class HelpDeskScenarioActions {

    @Inject TicketService ticketService;

    @ScenarioAction("create-ticket")
    Map<String, Object> createTicket(ActionContext ctx) {
        var ticket = ticketService.create(
            ctx.data("subject"),
            ctx.data("category") != null
                ? TicketCategory.valueOf(ctx.data("category"))
                : TicketCategory.OTHER);
        return Map.of("ticketId", ticket.id().toString(),
                       "status", ticket.status().name());
    }

    @ScenarioAction("resolve-ticket")
    Map<String, Object> resolveTicket(ActionContext ctx) {
        var ticketId = UUID.fromString(ctx.data("ticketId"));
        ticketService.resolve(ticketId, ctx.data("resolution"), ctx.actor());
        return Map.of("status", "RESOLVED");
    }

    @ScenarioAction("verify-ticket-exists")
    Map<String, Object> verifyTicketExists(ActionContext ctx) {
        var match = ctx.awaitMatchMap();
        var status = match.containsKey("status")
            ? TicketStatus.valueOf((String) match.get("status"))
            : null;
        var tickets = ticketService.findByStatus(status);
        if (tickets.isEmpty()) {
            throw new IllegalStateException("No ticket found matching: " + match);
        }
        var ticket = tickets.getFirst();
        return Map.of("ticketId", ticket.id().toString(),
                       "status", ticket.status().name(),
                       "category", ticket.category().name());
    }

    @ScenarioAction("verify-notification")
    Map<String, Object> verifyNotification(ActionContext ctx) {
        // Verify the demo notification was recorded
        return Map.of("verified", true);
    }
}
